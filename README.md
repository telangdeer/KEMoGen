# KEMoGen

[Project page](https://telangdeer.github.io/KEMoGen/)

This repository hosts the KEMoGen project website.

## Update the website

Edit `docs/index.html` to update the paper title, authors, affiliations, and abstract.

The figures are stored in `docs/assets/`. Add demo videos there and embed them in `docs/index.html` when available.

## GitHub Pages

In **Settings → Pages**, select **Deploy from a branch**, branch **main**, and folder **/docs**, then save.
The root `index.html` also redirects to the website when Pages publishes from the repository root.
